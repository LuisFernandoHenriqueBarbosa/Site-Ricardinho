# Projeto Final - Informática e Negócios

Este site foi desenvolvido como parte do projeto final da disciplina de **Informática e Negócios**, com o objetivo de aplicar na prática os conhecimentos adquiridos ao longo do curso.

## 🎯 Objetivo

Demonstrar habilidades em desenvolvimento web, integrando conceitos de tecnologia com estratégias de negócios.

## 🛠️ Tecnologias Utilizadas

- HTML
- CSS
- JAVASCRIPT

## 📌 Observações

Projeto acadêmico com fins educativos.
